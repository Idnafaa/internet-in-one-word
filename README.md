The whole internet in one word: **Brainrot**. An endless feed that melts your attention span one swipe at a time — funny because it is true. The program writes that single word, and nothing else, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Writes the one word (8 characters) to `/output/entry.txt`.
